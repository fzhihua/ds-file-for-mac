# Privacy / 隐私说明

**DS File for Mac is an unofficial local browser extension.** It does not collect, sell, or send personal data to the project maintainers, advertisers, analytics providers, or any hosted backend.

Data used solely to play your NAS video:

- The chosen NAS site URL and optional origin authorization are stored in `chrome.storage.local`.
- The launched video's path is parsed in memory from the browser's File Station playback navigation.
- A Synology session ID may be read from the authorized NAS `id` Cookie or obtained from a login request initiated by the user. It is kept temporarily in `chrome.storage.session`, scoped to that NAS origin.
- The NAS password typed into the handoff page is submitted directly to that NAS for authentication and is not stored; the password field is cleared immediately.
- The playback URL including SID is passed to IINA on your Mac, so the local OS, player, or related logs may retain the link.

The only outbound network traffic generated by the extension is toward the NAS origin(s) that the user explicitly authorized. No third-party telemetry or advertising libraries are included.

HTTP traffic is unencrypted; HTTPS should be configured with a trusted and properly verified certificate. You can clear temporary sessions in the popup, revoke site permission, and log out from the NAS to invalidate credentials.

Read the project security limitations in [SECURITY.md](SECURITY.md). Public Chrome Web Store distribution has not yet been reviewed or approved.
